# Articles

Your published work goes here. One file per piece, `.md` or `.txt`, named so you
can tell what it is without opening it.

**The starter kit ships none of it.** The archive is the one part of a workspace
that cannot be borrowed: Lighthouse's articles would be the first thing you
delete, and a voice guide derived from them would describe Lighthouse instead of
you. `GOLD-STANDARD.md` next door names five Lighthouse pieces that are missing
for the same reason, and the blog and newsletter channel files cite three of the
same five as their good examples.

Put five of your own best pieces in here before Walkthrough 1 step 6, which
reads them to write your voice file. Everything else that points at this
directory - the channel files, the `article-draft` skill, `INDEX.md` - starts
working as soon as there is something to find.

Delete this file once your own work is in here.
