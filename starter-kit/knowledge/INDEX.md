# Knowledge index

Read the file that matches your task. Don't read everything.

- `channels/lighthouse-blog.md` — SEO blog. Format, keyword rules, examples.
- `channels/the-signal-newsletter.md` — weekly newsletter. Opinion-led, ~400 words.
- `channels/linkedin.md` — company page and founder profile. Different rules for each.

## Voice — read alongside the channel file
- `voice/house-voice.md` — applies to everything. **Always read this one.**
- `voice/author-jana-novak.md` — only for pieces bylined Jana.

## Entities — read before making any factual claim
- `entities/products.md` — the only source of truth on what our products do.
- `entities/people.md` — names, titles, pronouns, bios, what each person can be quoted on.
- `entities/events.md` — dates, venues, official names, embargo status.

## Library
- `library/GOLD-STANDARD.md` — our best work and what each piece gets right.
- `library/articles/` — full archive of published pieces. Search here before
  proposing a topic, and use it to find internal links.
